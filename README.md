# 🖥️ Computer Graphics and Visualizations Laboratory

This repository contains practical implementations and laboratory experiments developed as part of the course:

**ICT-4108 – Computer Graphics and Visualizations Laboratory**

---

## 📘 Course Overview

This laboratory course focuses on the practical implementation of fundamental computer graphics algorithms and visualization techniques using programming tools.

It emphasizes how geometric primitives are generated, transformed, clipped, and represented visually using mathematical models and algorithms. The course bridges theoretical concepts of computer graphics with hands-on coding experience.

### Key Topics Covered

- Line drawing algorithms  
- Circle drawing algorithms  
- Ellipse generation  
- Two-dimensional transformations  
- Line clipping algorithms  
- Curve generation (Bezier, B-Spline)  
- Visualization techniques  

---

## 🧪 Laboratory Experiments

This repository includes implementations of the following experiments:

1. Digital Differential Analyzer (DDA) Line Drawing Algorithm  
2. Bresenham’s Line Drawing Algorithm  
3. Midpoint Circle Drawing Algorithm  
4. Bresenham’s Circle Drawing Algorithm  
5. Ellipse Drawing Algorithm  
6. Two-Dimensional (2D) Transformations  
7. Cohen–Sutherland Line Clipping Algorithm  
8. Liang–Barsky Line Clipping Algorithm  
9. Bezier Curve Generation  
10. B-Spline Curve Generation

## 🚀 How to Run

### 1. Clone the Repository

    git clone https://github.com/SajjadHossainSoykot/ICT-4108-Computer-Graphics-and-Visualizations-Laboratory.git
    cd ICT-4108-Computer-Graphics-and-Visualizations-Laboratory

---

### 2. (Optional) Create Virtual Environment

    python -m venv venv

Activate environment:

- Windows:

    venv\Scripts\activate

- Linux/Mac:

    source venv/bin/activate

---

### 3. Install Required Libraries

    pip install numpy matplotlib

---

### 4. Run Python Scripts

    python filename.py

---

### 5. Run Jupyter Notebook

    jupyter notebook
